# iKuaiBypass pure-domain subscriptions

Every .txt file contains one plain domain per line.
GEOSITE entries and convertible DOMAIN/DOMAIN-SUFFIX rules are included.
GEOIP, DOMAIN-KEYWORD, port rules and MATCH cannot be represented as pure domains and are intentionally omitted.
